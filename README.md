## Run Locally

### Prerequisites

* Node.js
* npm
* Gemini API Key

### 1. Install dependencies

```bash
npm install
```

### 2. Configure the API Key

Create or edit `.env.local` and add your Gemini API key:

```env
GEMINI_API_KEY=your_gemini_api_key
```

### 3. Run the application

```bash
npm run dev
```
